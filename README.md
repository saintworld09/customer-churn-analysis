# Customer Churn & Retention Analytics

## Project Overview

This project analyzes customer churn and retention patterns using Excel, SQL, Python, and Power BI.

The project is designed as an end-to-end and refreshable analytics solution, with reusable data transformation, analytical, and visualization logic.

## Business Problem

Customer churn can have a significant impact on revenue and long-term customer relationships. This project aims to understand customer churn patterns, identify factors associated with customer attrition, and develop a predictive approach for identifying customers who may be at higher risk of churn.

## Objectives

- Analyze customer churn patterns
- Identify factors associated with customer churn
- Analyze customer behavior and service usage
- Estimate the business impact of customer churn
- Develop a customer churn prediction model using Python
- Build an interactive Power BI dashboard
- Design reusable data transformation and analytical logic
- Test the solution with newly added customer records
